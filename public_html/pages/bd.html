Interactive Game Client: MERGE Internal Project Role: Creative Technologist

Overview

An engaging interactive experience that educates pet owners about parasite prevention through gamification. Players hunt down parasites in a beautifully rendered 3D environment while learning about the importance of year-round protection.

Key Features

3D Environment

Fully interactive 3D world built with Three.js, featuring dynamic lighting and smooth animations.

Sprite Animations

Custom sprite sheet animations for attack effects, creating engaging visual feedback for each parasite type.

Educational Content

Each parasite encounter teaches players about prevention methods and the importance of veterinary care.

Responsive Design

Optimized for desktop and mobile devices, ensuring a smooth experience across all platforms.

Technical Stack

  • Three.js for 3D rendering
  • GLTF models for optimized 3D assets
  • Sprite sheet animation system
  • Vanilla JavaScript for game logic
  • Web Audio API for sound effects

Results

The interactive experience has been deployed at veterinary conferences and trade shows, engaging thousands of pet owners and veterinary professionals. The gamification approach increased engagement time by 300% compared to traditional educational materials.
