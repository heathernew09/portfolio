Project Title

Placeholder content - set against the 'World Classic' theme of VMX 2026—the world's largest veterinary conference—we faced a sea of 700+ exhibitors and nearly 30,000 attendees at the Orange County Convention Center. In an environment defined by open-plan, high-concept experiences like Elanco's interactive Zen Garden, the Parasite Hunter AR game was designed to cut through the noise, turning the massive Expo Hall into an extension of our brand story.

The Challenge

With this years theme being "Go Beyond" we were looking to do something more than the traditional booth strategies. We needed something that would:

  • Drive qualified traffic from across the venue
  • Educate through active participation
  • Create memorable brand moments
  • Generate repeat engagement throughout the multi-day event

Key Features

3D Environment

Fully interactive 3D world built with Three.js, featuring dynamic lighting and smooth animations.

Sprite Animations

Custom sprite sheet animations for attack effects, creating engaging visual feedback for each parasite type.

Educational Content

Each parasite encounter teaches players about prevention methods and the importance of veterinary care.

Responsive Design

Optimized for desktop and mobile devices, ensuring a smooth experience across all platforms.

Technical Stack

  • Three.js for 3D rendering
  • GLTF models for optimized 3D assets
  • Sprite sheet animation system
  • Vanilla JavaScript for game logic
  • Web Audio API for sound effects
